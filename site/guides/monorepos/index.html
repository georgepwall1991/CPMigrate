Monorepos

Use CPM across multiple .NET solutions, not just one project tree

CPMigrate includes batch processing for teams managing several solutions in one repository. That matters when the problem is not “one migration” but “repeatable dependency policy across many app surfaces”.

cpmigrate --batch /path/to/repo --analyze
cpmigrate --batch /path/to/repo --batch-parallel --batch-continue
Proof asset: see the monorepo example bundled with CPMigrate.
Use batch mode to establish one repeatable migration and analysis workflow across many solutions.
