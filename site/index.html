Stop hand-migrating .NET solutions to Directory.Packages.props.

CPMigrate is a .NET dependency analysis CLI for app teams adopting NuGet Central Package Management. It generates Directory.Packages.props, audits dependency drift, fixes common issues, and updates packages with rollback when tests fail.
